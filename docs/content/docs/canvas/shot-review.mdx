# 镜头审核与替换

镜头审核台属于具体画布项目。在画布顶部点击「审核」进入，不会修改原画布节点。

## 审核一个镜头

1. 在左侧选择镜头，核对固定时间、对应稿件、画面目标和镜头构图。
2. 满意时点击「通过并下一镜」。有问题时填写审核说明并标记「待修改」。
3. 所有选版和审核状态会保存到项目输出目录的 `review/review-project.json`。

## 重新生成

- **局部纠错**：当前画面作为第一参考图，只修正明确问题；适合发型、手部、道具等局部错误。
- **重新设计**：不把当前画面作为参考，使用统一画风、场景锚点和相邻镜头重新构图。

两种模式都会把人物、场景和画风文字锁写入提示词。生成结果保存为新版本，不覆盖旧图；点击历史版本即可回滚选版。

### 上传人物或对象参考图

在修改要求下方填写参考对象名称，例如「父亲」「成年主角」或「金镯子」，再点击「添加参考图」。该图片只参与 AI 生成，不会直接替换当前画面。

实际请求顺序会显示在「本次 API 参考顺序」中：

- 局部纠错：当前待修原图 → 用户人物/对象参考 → 画风、场景和相邻镜头；
- 重新设计：用户人物/对象参考 → 画风、场景和相邻镜头，不传当前错误构图。

提示词会逐张说明参考图职责。人物参考只锁定同名角色的身份与外观，不复制参考图背景、姿势和构图，也不得影响画面中的其他人物。单个镜头最多启用 4 张用户参考图，总请求最多传入 6 张图片。

从页面移除参考图后，它不会再参与后续生成，但文件和历史版本中的引用记录会保留，便于追溯已生成候选图使用过哪些人物素材。

## 人工替换

「人工替换图片」位于「直接替换最终成品」区域，与生成参考素材相互独立。选择外部成品图后，页面会按中心安全区归一化为 16:9，并作为新版本保存。时间戳、镜头时长、配音和字幕均不改变。

## 导出三件套

点击「导出三件套」会冻结当前 102 个镜头的选版快照，并异步生成：

- 无字幕、无音轨的静音 MP4；
- 独立 48 kHz 单声道长配音 WAV；
- 独立带时间戳 SRT。

SRT 默认采用纯净屏幕字幕：标点仍用于 TTS 语气和字幕切段，但交付文本只保留汉字、字母、数字与必要空格，不把稿件标点写进画面字幕。

每次导出位于 `review/exports/<export-id>/`，其中 `picture-lock.json` 记录逐镜头版本和图片哈希，`receipt.json` 记录时间线与交付文件哈希。

## 局域网使用

Web UI 继续监听 `0.0.0.0:3000`。Canvas Agent 启动时设置 `CANVAS_AGENT_HOST=0.0.0.0`，审核图片会通过受连接 token 保护的 Agent 地址提供，不依赖浏览器本机 Blob 地址。
