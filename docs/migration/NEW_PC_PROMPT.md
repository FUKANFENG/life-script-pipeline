# 新电脑首次交给 Codex 的指令

把本迁移包解压后，在 Codex 中打开本目录，然后发送：

```text
请先完整阅读 README.md、AGENTS.md、workflow/STORY_PRODUCTION_PLAYBOOK.md 和 workflow/MIGRATION_CONTRACT.md。

我的 Infinite Canvas 工程位于：<填写新电脑路径>
这台电脑已经配置好 XG 生图接口，请保留现有 XG 配置。

请先只运行环境检查，确认基线和风险；检查通过后安装工作流，初始化依赖，重新注册本地 Canvas Agent MCP，并完成离线测试。不要复制或输出任何 API Key。最后告诉我还需要补充哪些本机环境变量，以及如何进行 10～15 秒真实验收。
```

安装和验收完成后，处理新剧本时可以直接发送：

```text
这是一个新的剧本。按照人生剧本工作流，先计算 TTS 时长并制定章节、场景复用、人物阶段、镜头密度和交付计划，暂时不要开始批量生图。
```
