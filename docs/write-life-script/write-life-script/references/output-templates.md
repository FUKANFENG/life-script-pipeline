# 交付文件模板

## 文件命名

```text
<output-directory>/
├── 改编规划.md
├── 人生副本_<标题>_完整稿.txt
└── 质量检查.md
```

标题应描述人物面临的具体命运，不使用空泛的“某某的一生”。

## 改编规划.md

```markdown
# 《<标题>》改编规划

## 改编定位

- 类型：<影视/人物/历史/案件/观点/原创>
- 叙事视角：<主角>第二人称“你”
- 核心冲突：<一句话>
- 核心命题：<不是口号，而是人物选择>
- 目标时长：约 <范围>
- 目标画面：约 <数量>

## 原稿处理

1. <删除什么及原因>
2. <保留什么及原因>
3. <需要核验什么>
4. <修补哪一处逻辑>

## 章节与画面分配

| 章节 | 剧情功能 | 主要内容 | 建议画面 |
|---|---|---|---:|
| 1. <名称> | <功能> | <内容> | <数量> |

## 场景复用与一致性

- <核心场景>
- <人物年龄和造型版本>
- <核心道具或视觉母题>
- <哪些连续台词必须复用场景>

## 下游提示

- SRT 按语义切分，每条原则上不超过 20 个汉字。
- 配音、纯画面视频和字幕独立交付。
```

## 人生副本_<标题>_完整稿.txt

```text
今天你要体验的人生副本是：<身份 + 异常/危机 + 极端选择 + 未解问题>

<第二人称完整正文>
```

正文不要包含 Markdown 标题、编号、来源脚注、制作说明或字幕时间码。
